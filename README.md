# solitaire-alternative-bg

Digital companion and web tools for solitaire & cooperative board games using a standard 52-card deck.

## Featured Games

1. **Take Time**
   - 12 Chapters & 40 Clock Boards
   - Interactive high-res board viewer with 60° rotation mode (Chapter VIII)
   - Integrated HD 11-page Leaflet rulebook viewer with zoom & pan
   - Standard card converter setup (Solar / Lunar 24-card deck)

2. **Regicide**
   - Boss tracker, HP counter, and combo management

3. **Nana (Trio)**
   - Digital helper and card tracker
